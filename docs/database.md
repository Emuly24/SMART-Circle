# SMART Circle v2 — Database

The database is defined by the numbered files in `database/migrations/`. `database/schema.sql`
is the same thing in one file (generated by `php tools/build-schema.php`) for importing with phpMyAdmin.

## Replacing the old database on InfinityFree

**Option A: a new, empty database (recommended)**

1. Back up the old database: phpMyAdmin → select it → **Export** → Quick → SQL. Keep the file.
2. InfinityFree control panel → **MySQL Databases** → create a new database.
3. Put the new database's name, user, password and host in `secrets.php`.
4. Open `https://your-site/install`: it creates every table and your tutor account.
   (Or import `database/schema.sql` in phpMyAdmin first, then open `/install` to create the tutor account.)

**Option B: the same database as the old site**

1. Back up the old database (as above). This step is essential.
2. phpMyAdmin → select the database → **Import** → `database/drop-old-site-tables.sql`.
   It refuses to run if v2 is already installed, so it cannot delete v2 data.
3. Open `/install`.

**Later updates:** when new code adds a migration, the tutor dashboard shows **"Update database"**.

Notes:
- Phone numbers are stored as `+265XXXXXXXXX`; sets of subjects as comma-separated keys
  (`mathematics,physics,chemistry,biology,english`); forms as 1–4.
- Seats: `intakes.seats_per_group` (default 3) per form per gender, so 3 girls + 3 boys per form = 24 seats.
- Tracks: Forms 1–2 `general` (all five subjects); Forms 3–4 `science` (takes Physics **and**
  Chemistry: all five) or `humanities` (Mathematics, Biology, English grammar).
- The entry quiz in `0004_seed.sql` is a **draft**: review the 40 questions before advertising.
- Uploaded files (lessons, school reports, photos) live in `storage/`, never in the database.
